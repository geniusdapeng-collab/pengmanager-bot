# Native video quickstart

Preserve the original intent and requested duration when making a plan.

```sh
node scripts/video-standard.mjs plan --input-file -
```

Before any paid call, inspect the current supplied local runtime, verify the exact project and sources, and use its owner-approved capabilities. A plan is a private intermediate result. A completed video requires actual playable output and recorded verification. Use the public BOT workbench to track the applicable handoff and evidence. The local edit-post package can accept owner-approved source recordings where the installed toolset supports them.
